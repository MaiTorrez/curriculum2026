Torrez Maira Curriculum Vitae

Este es el primer trabajo de la materia de Computación III del año 2026 1er cuatrimestre. El trabajo consiste en desarrollar un Curriculum Vitae con los datos del alumno, esto no es más que una razón para aprender a dominar el uso del código HTML5 y aplicar estilos mediante .css, a su vez, la alinecion y distribución de espacios se realizó con la herramienta flexbox.

Especificaciones técnicas
Se trabajó en una pantalla de 1920 x 1080 px 
El editor de código que se usó es Visual Studio Code
